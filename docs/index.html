How it works

Index

Point it at the cloud’s docs (or your own). It chunks + embeds them locally into an embedded vector store — GPU-accelerated.

Ask or design

Ask a how-to, or “design …”. It retrieves the right sources across services and composes a grounded, cited answer.

Visualize

Designs render as a live 3D architecture — real service icons, animated data flow, labeled connections you can orbit & zoom.

Get started

Two commands and it’s running — nothing to install, nothing to configure. It arrives already knowing AWS, Azure and Google Cloud.

# 1. grab the compose file
curl -LfO https://raw.githubusercontent.com/agentcloudai/agentcloud/main/docker-compose.yml

# 2. start it
docker compose up -d

# then open http://localhost:8000 and paste your OpenAI key when it asks

The first launch takes a few minutes while it downloads itself and everything it knows about AWS, Azure and Google Cloud. After that it opens instantly — and runs entirely on your machine, so your questions and your key never leave it.

Prefer Python? pip install agtcld
